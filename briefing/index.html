📄 前沿论文

Towards Portable Specification of the Agent Harness（arXiv 2610.40917）

大模型只能通过「外壳」行动：工具定义、上下文组织、循环控制、错误处理。这篇指出 harness 至今没有公认规范，导致同一模型换框架就换表现、失败也无法归因，并提出一套可移植的规格描述。做 agent 工程的，这是少见的「先把地基画清楚」的工作。

🐥 小鸡点评：模型能力之外，真正决定成功率的是这层工程外壳——这也是为什么同一模型在不同产品里差别巨大。

More Rules, Longer Lists? Benchmarking Self-Evolving Agents on a Hidden-Rule Curriculum（arXiv 2610.40758）

自进化智能体会根据反馈重写自己的持久状态，但「没人告诉它的规则」能不能学会，此前缺乏测试。作者设计隐藏规则课程做基准，发现多数智能体能把规则写进记忆通过当前任务，却学不到可迁移的规则本身。

🐥 小鸡点评：会记答案不等于会做题。这条对「给 agent 加记忆就能变强」的乐观假设，是一次直接的证伪。
