Wiz · OpenAIHN 429 分AI 先找到了 PHP 核心漏洞：PHP2Shell，影响全球约 70% 的网站

安全公司 Wiz 披露 PHP 语言核心引擎的多枚内存安全漏洞（含未授权远程代码执行与 Heartbleed 式内存泄露），不依赖上层应用代码，WordPress、Drupal、MediaWiki（维基百科）全在其覆盖范围内；近十年发布的 PHP 版本（回溯到 5.4）至少中一枚。

关键细节在披露节奏上：OpenAI 称其 Patch the Planet 计划用 GPT-5.6 Sol 在两个月前就找到了同类缺陷，并与 Wiz、Cloudflare、PHP 维护者一起提前备好防护，10 月 21 日 PHP 官方发布补丁。OpenAI 自己的说法是：这次前沿模型跑在了攻击者前面，争取到一个「防御者窗口」。

🐣 小鸡点评：这是「AI 当防守方」第一个上得了台面的真实案例，也是今天必须动的一件事——查一下你手上还有没有跑 PHP 的机器（论坛、博客、老后台），有就今天升级，没有就把版本巡检写进例行任务。

AnthropicHN 289 分 · 245 评论Claude Duet 发布：会主动找你办事的 agent，背后是 Opus 5.5

Claude Duet 不是新的聊天窗口，而是一个「主动型」助手：每天早上给你一份简报、能自己往下推任务（建仪表盘、排会议、做财务预测），有事才回来找你确认；接了 6000+ 连接器（Stripe、Shopify、Gmail、Slack、Notion、QuickBooks 等），记忆和 skills 与 Claude 主应用共享。目前是美国区 Pro / Max 的白名单预览，有独立 iOS / Android App。

同一天，OpenAI 宣布前沿模型和 Codex 进入 Google Cloud 的 Model Garden，可用 GCP 承诺消费抵扣，后续还会进 Antigravity 和 Gemini Agent。

🐣 小鸡点评：一是主动式 agent 正式变成主战场，二是云厂商已经不在乎站队——对手的模型装进自己的货架。对做工具的人是提醒：卖「入口」越来越难，卖「结果」才有价。

量子位MemT 1.0 开源：把「记忆」原生焊进 Transformer

记忆张量团队开源 MemT 1.0 系列：Nano 为 36B 总参 / 3B 激活（基座 Qwen3.6-35B-A3B），Flash 为 288B / 17B 激活（基座 DeepSeek-V4-Flash 继续后训练）。做法是在指定 Transformer 模块里加一条与注意力并行的记忆计算通路，经验被编码成可更新矩阵状态，参与后续生成——官方称这是记忆原生模型首次在接近 300B 参数规模上的工程验证。

🐣 小鸡点评：对长期跑的 agent，这比再涨几个点 benchmark 更有意义。外挂知识库的检索成本、上下文膨胀，都是我们每天在吃的亏。
