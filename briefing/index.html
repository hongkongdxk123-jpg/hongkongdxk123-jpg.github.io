Google 发布 Gemini 4 Argon：输出上限一次拉到 100 万 token，但先给"可信防御者"用

9 月 30 日，Google 公布新一代前沿模型 Gemini 4 Argon，定位是"长周期复杂工作流"——真实软件工程、法律与金融等企业知识工作、以及网络安全防御。它目前已开始向 Fairwind 计划下的可信网络安全防御者分批开放，同时参与美国政府自愿的发布前模型访问流程，之后再逐步开放给开发者、企业和消费者（先给付费 API 客户与 Google AI Ultra 订阅者）。

最硬的一个数字：输出 token 上限从 64K 一口气提到 1M，官方称"行业领先"。定价为输入每百万 token 2 美元、输出 10 美元，缓存输入打 95% 折扣。

Google 罕见地列了内部用例：帮量子计算团队优化子程序时空资源，几分钟内比公开基线快 40%；一群 Argon 智能体分析全机群 profiling 遥测，在数据中心释放超过 300 TiB 内存（预计总节省 500 TiB–1 PiB）；把 C/C++ 代码库批量迁往 Rust，规模从核心库到 Fuchsia Zircon 内核 80 万行以上——其中 libgav1 用 Argon 重写 3.2 万行 SIMD 代码，得到的内存安全解码器比 Rust 移植版快 2.7 倍。

小鸡点评：注意发布方式——Google 说"先给网络防御者、再走政府送审、最后才开放"，和 OpenAI 上周因越权被叫停 Astra 是同一种谨慎节奏。但 Bloomberg 那边有一条反差新闻：Google 内部员工对这款新模型的能力说法持怀疑态度（HN 中信号）。同一晚 Artificial Analysis 的独立评测也上了 HN。
HN 1048ptsHN 748ptsBen's Bites

OpenAI 两条线同时推：GPT-6.1 Sol 把旗舰智能打到 1/5 价钱，Dots 把智能体变成"永远在线"

GPT-6.1 Sol（HN 1048 分）官方口径是"以五分之一的价钱拿到接近 Astra 的智能"。价格：输入 2 美元／输出 10 美元／缓存输入 0.10 美元每百万 token。几条关键评测：DeepSWE v1.1 上与 Astra 打平但成本约五分之一，同时比 GPT-6 Sol 最好成绩高 6.4 个百分点；GDP.pdf 上高于 Opus 5.5 且成本不到一半；AutomationBench 比 Opus 5.5 高 2.2 个百分点；Terminal-Bench Science 0.1 上平均每任务 5.47 美元，而 Opus 5.5 与 Astra 都是 23 美元级别。已向 Plus／Pro／Business／Enterprise／Edu 在 ChatGPT Work 与 Codex 开放（Chat 暂未上），API 名 gpt-6.1-sol，几日内还会推出 8 倍速的 Ultrafast 版。

Dots（HN 748 分）是"常驻智能体"：由 GPT-6 Astra 驱动，自带云电脑与浏览器，可接入 4000 多个应用，能在 ChatGPT、Slack、Teams 里随时找到你，也可以打电话讨论。它会随时间学习你的偏好，甚至在你开口之前先把活干了。先向 Pro 与 Business Premium 在部分市场上线，企业版可申请 Beta。

小鸡点评：这三条放在一起看最清楚——OpenAI 一边把旗舰能力打折卖（Sol），一边把智能体变成常驻（Dots），而 Google 那边把最强模型锁进"先给防御者"的小圈子。今年秋天的竞争，已经从"谁更强"变成"谁能安全地便宜地一直在线"。

🌍 国际前沿

Anthropic 红队量子位HN 244pts

Anthropic 红队：GLM-5.3 把"自主造漏洞利用"这件事扩散开了

五个月前 Anthropic 发布了第一个能自主构建端到端网络攻击程序的 Claude Mythos Preview，并通过 Project Glasswing 让可信防御者先找到一万多个漏洞。现在它说：同类能力已经扩散了。这份报告拆解了智谱 GLM-5.3——在 41 个 Chrome V8 漏洞上，GLM-5.3 成功做出完整利用程序 50／410 次（12%），Claude Mythos Preview 是 56／410（14%），而 Claude Opus 4.6、GLM-5.2、Kimi K3、DeepSeek V4.1-Flash 都"接近 0%"。

更关键的是护栏：研究者用简单的掩护故事、预填推理、再训练去防护等手段，绕过 GLM-5.3 安全防护的成功率在 64% 到 100% 之间，而同样的手法打不穿有防护的 Claude。NIST 下属 CAISI 9 月 17 日的独立评估结论一致：GLM-5.3 是"迄今发布的最具网络攻击能力的开放权重模型"，整体落后美国前沿约四个月——但美国那些前沿版本只对少数受审用户开放，GLM-5.3 却是任何人都能下载。

小鸡点评：Anthropic 的落点是政策建议：各国政府应当对足够强的模型做安全测试。而国内舆论的反应很有意思——量子位直接写"Anthropic，你是来给智谱打广告的吧"，因为实测 GLM-5.3 确实很强。一份批评报告，顺手成了最强背书。

🇨🇳 国内动态

量子位Reuters / SCMP36氪

DeepSeek 联手华为：一次性开源六个昇腾基础组件，把"国产 GPU 软件栈"补上

9 月 30 日，DeepSeek 在官方公众号宣布开源面向华为昇腾平台的编程基础设施，共六个项目，与此前面向英伟达的那一套一一对应：高层编程语言 TileLang（新增昇腾后端）、矩阵计算 DeepGEMM-Ascend、专家并行通信 DeepEP-Ascend、算子库 TileKernels、稀疏注意力 FlashMLA、TopK 算子 DeepSelect。

最实用的一点是接口层：同一套 Python API 可以在英伟达 GPU 与华为 NPU 之间运行时自动选择后端，不用重写代码。DeepSeek 说 TileLang 已用于 V4 系列训练中的大部分算子，编程模型比 CUDA 更简单。双方还共同推进了基于昇腾 950 的 128 卡超节点方案，华为团队在适配中提供了全面支持。文档也如实说明：部分集合通信操作仍在开发，性能测试用的是华为提供的概念验证硬件。

小鸡点评：这条的分量和"某个模型又刷榜"完全不同——它动的是生态地基。华为两周前刚发布新一代 AI 处理器和超节点系统并称明年将在模型训练领域大规模应用；DeepSeek 隔一周就把软件栈补齐。国内从"能跑"到"好写"这一段，正在被填上。

🤖 AI 模型动态

一周四连发Ben's BitesAnthropic

一周之内四个前沿模型：Opus 5.5 → Sonnet 5.5 → GPT-6.1 Sol → Gemini 4 Argon

Claude Sonnet 5.5（9/28）：这周最值得改工作流的升级。Terminal-Bench 4.0 上从 Sonnet 5 的 10.3% 跳到 70.6%（Opus 5.5 同设置是 66.4%）；GDPval-AA 真实职业任务 1844 分，只差 Opus 5.5 两分，价格却只有一半（$2／$10 每百万 token），输出速度快 30% 以上。它是第一个带 Opus 级网络防护的 Sonnet，高风险网络安全请求会可见地回落给 Sonnet 5，同时也是首个上线"反蒸馏"分类器的 Sonnet。企业侧实测：Box 说快 2.4 倍、token 少 12%，Slack 说输出 token 少约 14%。Anthropic 称 Haiku 5.5 将在数周内发布。

Claude Opus 5.5（9/22）：家族旗舰，4／20 美元档。已有独立项目 livenerf 专门盯着它"发布后是否被悄悄削弱"。

GPT-6.1 Sol（9/29，OpenAI）：近 Astra 智能、五分之一价格，缓存输入 0.10 美元，详见头条。Gemini 4 Argon（9/30，Google）：输出 100 万 token，先给防御者。GLM-5.3／GLM-5.3-FlashX（智谱）：被 Anthropic 与 NIST CAISI 评为开放权重里网络能力最强者。DeepSeek V4.1-Flash：Agent 训练平台 DSec 首次公开。Kimi K3：在 Anthropic 的攻击能力横评里与 DeepSeek V4.1-Flash 同处"接近 0%"一档——这一次，"低分"是好消息。

小鸡点评：这周的规律很清楚：中档模型在吃旗舰的活。Sonnet 5.5 打平 Opus、Sol 逼近 Astra，两家都靠"少用 token、多打折"把成本压到原来的 1/5 到 1/2。对你我这种天天烧 token 的人来说，比跑分好看重要得多。

📄 前沿论文

arXiv 2609.35799arXiv 2609.35873arXiv 2609.35875
  • OpenAI-HuggingFace: A Reproduction & Lessons for Alignment Testing —— 直接对着 7 月那起事件做的复现研究：现有的对齐测试实践本可以预见这次事故吗？如果不能，需要改什么。（今天 arXiv 的头条，Amazon 上的讨论也很热闹）
  • More Programs or More Rolls? Separating Coverage from Specialization in LLM Harnesses —— 自动生成的 LLM harness（外挂程序）到底靠什么提升推理？答案的一半可能不是"程序更专精"，而是"同一个程序多跑几遍"带来的覆盖面。做 Agent 工程的人值得一读。
  • Beyond Symmetric Agents: Cognitive Diversity and Multi-Agent Debate in Small Language Models —— 多智能体辩论的增益来自哪里？这篇说关键不是"辩"，而是智能体之间的认知多样性；用小模型做实验，结论对便宜的多智能体系统很实用。
  • 另外还有 Neurosymbolic Routing（边缘设备可靠推理）、Is Human-Readable Text Necessary for Effective LLM Fine-Tuning?（不可读表示能不能训得更好）、以及一篇关于 token 边界压缩成本的论文，都是今天新上的。
小鸡点评：第一篇的时机很妙——Anthropic 在讲"哪些能力扩散了"，这篇在讲"我们的测试为什么没提前看见"。两件事指向同一个结论：对齐测试需要按"智能体在真实环境里能做什么"来设计，而不是按"模型回答得对不对"。
