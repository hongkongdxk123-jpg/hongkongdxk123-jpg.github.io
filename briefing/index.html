蚂蚁灵波开源 LingBot-Touch：先给触觉做“翻译”，机器人拉拉链成功率从 39% 提到 59%

一个反直觉的实验：给灵巧手五个指尖都装上触觉传感器，反而更笨了。Sharpa Wave 配 π0.5，拉拉链成功率从 39% 掉到 15%；交接盒子从 57% 掉到 48%；换 XHand 六项任务平均也从 49.71% 降到 48%。原因是触觉读数大部分是 0，接触时又稀疏带噪，视触觉、磁触觉、压阻式三类传感器给出的数字完全不可比，动作模型“看不懂还得硬用”。蚂蚁灵波的做法是在传感器和模型之间加一层翻译：把原始读数转成“碰在哪儿、多大劲、力往哪偏、有没有打滑”，再喂给模型。同一个 π0.5，拉拉链成功率升到 59%，比完全不用触觉还高 20 个百分点；交接盒子从 48% 回到 63%。模型今天已开源。

小鸡点评：这条的方法论比机器人本身更值钱——原始数据不能直接喂模型，中间要有一层“翻译成模型能理解的语言”。你手上的表格、聊天记录、门店流水，全是这种“原始读数”。

AlphaProof Code：AI 第一次把 Signal 协议的代码形式化验证到底

DeepMind 公布 AlphaProof Code：一个多模型 Agent 框架，把形式化验证按研究团队的方式拆分——人类专家和 AI 一起决定“要证明什么”，再由一组 Agent（底层是 Gemini Carbon）去证。这次目标是 Signal 协议的密码学实现，长期被视为安全领域的“大挑战”。结果：人类与模型协作把安全目标翻译成数学规格并逐条复核，Agent 生成了超过 600 万行 Lean 证明代码，随后自查、人类再抽查。官方称这是首次有 AI 对广泛部署的密码协议做到这种深度的形式化验证，也是该协议实现首次被任何方法（含纯人工）完整验证。

Formalizing CPython：61 万行 Lean，顺手挖出 418 个 Python bug

两位研究者让 Opus 5.5 把 CPython 的函数逐行改写成 Lean（可机器检验的证明语言）：每个改写都先对上万条输入与真实 Python 比对，再由另一个“没参与写”的 Agent 复核，通过才算数。目前 4,071 个函数通过复核，产出 613,318 行 Lean、1,539 个文件、18,898 条定理与引理，全部在每次构建时由 Lean 证明检查器验证；过程中向 Python 提交了 418 个 bug 报告。

Fable 5.2 的实测里，已有人用一条提示词在 52 分钟内交片、渲染成本约 38 元。做法：挑一条已拍好的旅拍路线，写清镜头、光线、时长、字幕，只做 15 秒样片，对比现有人工剪辑的质感与工期。

小鸡点评：只做样片验证，不进正式交付。真要做商业片，版权、肖像、平台规则都得先过一遍。
