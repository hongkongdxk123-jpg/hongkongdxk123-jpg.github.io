🔥 今日头条

1. DeepSeek-V4.1-Flash 正式发布：552B MoE 非对称架构，性能反超旗舰 V4-Pro
9月10日 DeepSeek 发布新架构家族里最小的模型 V4.1-Flash：552B 参数 MoE，非对称 Causal Encoder–Decoder 架构，输入仅激活 8B、输出激活 16B，补齐原生视觉理解。第三方测试显示它在性能、成本、速度与总运行时长上全面超过旗舰 V4-Pro。KV cache 只需上一代的 1/4 HBM、1/8 SSD 存储——而"缓存命中"费用正是 Agent 成本的大头。API 已上线（model=deepseek-flash）；V4-Pro 自 9月14日 04:00 UTC 起全部路由到 V4.1-Flash。
官方公告 · 技术报告 · HN 935分
💬 这条你可能用得上：1/8 SSD 缓存意味着长会话 Agent 的存储成本大降；但 V4-Pro 9月14日就全面切换了，有依赖旧版接口的（含 WorkBuddy/CodeBuddy、OpenCode 已适配）要提前改。
2. Cognition 发布 SWE-2：FrontierCode 50.0%，仅比 Fable 5.1 低 1 分却便宜 64%
9月10日 Cognition 放出新编程模型 SWE-2：FrontierCode 1.1 Main 拿到 50.0%，只比 Claude Fable 5.1 低 1 分，成本便宜 64%；Terminal-Bench 2.1 达 92.8%，反超 Fable 5.1 的 91.4%。做法是把 RL 首次扩展到"万亿参数级"，一次训练覆盖所有推理强度档位，基座是 Kimi K3（2.8T）。同一天 Dioxus Labs（YC S23）宣布加入 Cognition。

📄 前沿论文

MERIT：长期记忆对工具型 Agent 到底值不值？
论文指出：现有记忆评测（LoCoMo、LongMemEval）都在测"能不能回忆对话"，却没测"记住的事实是否真的改变了 Agent 的工具调用行为"。MERIT 提出成本感知评测——记忆不是越多越好，得算清它的开销与收益。
arXiv:2609.05441
AutoFyn：不改权重，靠"持久状态"做长时程 Agent 迭代
借鉴专家迭代（Expert Iteration）：模型权重全程冻结，每轮从全新会话开始，靠验证过的奖励信号更新持久状态。为非参数化 Agent 训练给出了一条新路径。
arXiv:2609.05446
ARC-Bench：闭环重规划会"掩盖"世界模型的动作排序失效
冻结 JEPA 世界模型用潜空间距离给动作打分，隐含假设"潜空间更近=动作更好"。ARC-Bench 揭示：闭环重规划会把这个问题盖住，评测结果具有误导性。
arXiv:2609.05461
