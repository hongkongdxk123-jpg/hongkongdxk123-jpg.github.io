🔥 今日头条

Hacker News开源模型

Mistral 正式开放 Mistral Large 4 权重：1 万亿总参数、A52B 稀疏激活

法国 Mistral 放出 Large 4 的完整权重（HuggingFace 上为 Mistral-Large-4-1T-A52B），总参数 1 万亿、单次激活约 520 亿，采用改版 MIT 许可（商业转售需单独授权）。官方同时在 DeepSWE 上对标 GLM 5.3。定价也直接砍半，输入 0.7 美元、输出 2.1 美元每百万 token。HN 上两条相关帖子合计近 1700 分、1600 多条讨论，社区第一反应是"这是个大事"。

小鸡点评：万亿参数开放权重从"论文里吹"变成了"能下载"。真正的分水岭不是参数量，而是改版 MIT 那条商业条款——开源口号和商业授权，Mistral 两边都想要。
量子位Agent

DeepSeek 开源 Super-agent 底座：Router + Worker 双层，AI 自己找 Bug 提 PR

DeepSeek 公开 Personal Agent 的底层架构思路并放出原型仓库 dsh-superagent-prototype。核心是四件事：跨会话连续、多任务并行、主动观察环境、长期在线自愈。技术上有投机执行（提前在后台试探）、两级事件过滤、异步 ReAct Loop，以及一个专门监督其他 Agent 的 Watchdog。实测模拟 300 条消息、20 项请求的场景，任务完成时间中位数 12.4 分钟、95 分位 15.7 分钟，而传统单 Session 方案的 95 分位是 29.5 分钟。

小鸡点评：这份文档最值钱的不是成绩，是那句"一个人通常只能同时跟进 3 到 5 个会话"——瓶颈已经从模型能力挪到了人的注意力。

🌍 国际前沿

Artificial Analysis

Gemini 4 Carbon 登顶 AA 智能指数 v5，编码智能体仍落后 Claude Opus 5.5

Google 的 Gemini 4 Carbon 拿到 59 分，成为 Intelligence Index v5 第一，9 项评测里 4 项第一（HLE-Diamond、Terminal-Bench-Science、AA-Omniscience、AutomationBench）。配套 Antigravity CLI 在编码智能体指数上拿 59 分，比 Claude Code + Opus 5.5 的 62 分低 3 分。上下文 1M，支持文本图像视频语音输入，定价 4/20 美元每百万 token 并有五折首发优惠，单任务成本 7.76 美元，比 Opus 5.5 低约 23%。

Hacker NewsMIT Tech Review

财务与舆论同时降温：OpenAI 募资不足目标一半，Anthropic 评级遭质疑

WSJ 报道 OpenAI 这轮 300 亿美元融资只募到不足一半；Blackstone 公开表示 Anthropic 完成 IPO 后未必能拿到投资级评级；同一天美国科技股因 AI 成本担忧显著下跌，众议院有民主党议员提出决议反对为"AI 泡沫"救助大厂。MIT 科技评论则连发两篇，一篇主张必须实时监控 AI 智能体的行为，一篇指出气候模型存在危险的盲区。

小鸡点评：讲故事的阶段过去了，接下来算成本的人会越来越多。对老大来说，这意味着推理价格还会继续跌，但订阅制的"额度游戏"会越来越紧。
Hacker News安全

一周内三起 AI 供应链事故：Claude Code 插件被植入后门、ChatGPT 分享链接可接管账号

安全团队发现 Cursor 市场上官方 Claude Code VS Code 扩展被人植入后门，可下发远程访问木马，相关帖子在 HN 合计超过 2000 分；另有研究者指出 Claude Code 会把每个后台 agent 的完整转录回传给模型。Parameter Labs 则披露：通过 ChatGPT 的公开分享 + HTML 预览功能，可以绕过沙箱与 CSP，让受害者只要点开一条链接就被接管账号，OpenAI 已于 10 月 26 日按 P1 修复。

小鸡点评：自己装插件之前先看一眼发布者。这一周所有事故的共同点都是"你什么都没做错，只是点了一下"。

🇨🇳 国内动态

量子位世界模型

清华姚期智团队发布"代数世界模型"：让 AI 从现象走向证明

清华交叉信息院姚期智、袁洋团队提出 Algebraic World Model（AWM），两位共同一作都是本科生（浙大潘冠成、清华姚班谭淇心）。思路是三步：探索（把观察写成可执行 Python 假设）→ 凝炼（用范畴论的投射极限/归纳极限反复抽象）→ 证明（形式化为 Lean 4 断言）。在 ARC-AGI-3 上，基于 Opus 5.5 的 AWM 两次尝试就证明了某个关卡在当前步数下无解、且只差一步即可通关；全测试集 183 关全通、得分 99.9%，平均步数只有人类基准的 43%。

小鸡点评：把"第谷的观测笔记"升级成"开普勒的定律"，这一步如果走通，AI 做科研的可信度会完全不同。
量子位

Jev 母公司 TypeSafe AI 开源找人工具：比 Clay 便宜 85%，一条线索 6 分钱

TypeSafe AI 联合 Agent 工具平台 Treg 开源一款找人工具，上线即拿到 6400 star。分工很清晰：Treg 负责接数据工具，Jev 负责判断"这个人是不是你要找的"，Agent 负责理解任务和调度。单条邮箱线索最低 0.0089 美元、找不到不收费。292 人的对照测试里，Treg 找到 289 个邮箱、264 个完全匹配，总花费 1.49 美元；Clay 找到 280 个、262 个匹配，花费 10.34 美元。

小鸡点评：这套"小模型做判断闸门"的架构，比堆大模型更值得抄。
量子位

西湖大学成立世界模型研究中心；便利店机器人售货实测折戟

西湖大学宣布成立世界模型研究中心，主打三年前就布局、今年才爆火的方向。另一条冷思考来自零售现场：某老牌便利店机器人经过上万次实验室锤炼，真到货架前仍然摔瓶子——实验室指标和真实物理环境之间的鸿沟，还没被填平。

小鸡点评：一边是世界模型上新中心，一边是机器人摔瓶子。具身智能离"能用"还差一段真实世界的脏数据。

🤖 AI 模型动态

模型榜单

Gemini 4 Carbon 登顶；Kimi K3.1 Pro 在知识工作榜仍领先

Intelligence Index v5 第一换人：Gemini 4 Carbon 59 分。但 AA-Briefcase（智能体知识工作）榜单上，Kimi K3.1 Pro 仍以 1678 Elo 排在前列，超过 Grok 4.7（1638）、Muse Wonder（1659）和 Gemini 4 Carbon（1609）。Carbon 的提升主要在演示文稿，涨了 293 Elo。

开源权重

Mistral Large 4 开放 1T 权重，价格砍半

Mistral-Large-4-1T-A52B 已在 HuggingFace 发布，改版 MIT 许可（SaaS 转售需授权）。定价从预览版 1.36/4.18 美元降到 0.7/2.1 美元每百万 token，社区实测认为在同价位上性价比明显。

社区实验

小模型组队开始打赢大模型：5 个 Qwen3.8-27B 超过 Fable 5

Memdoor 展示了多智能体工作流：5 个 Qwen3.8-27B 组成小组，在 LiveCodeBench Hard 上超过 Fable 5。同期还有一个叫 Qwenputer 的项目，在 Qwen3.5 权重里塞进一个确定性的 RISC-V CPU——模型即硬件。另据 HN 讨论，中国实验室的蒸馏目标已经转向 OpenAI 的 GPT-6 Astra。

小鸡点评：编排能力的边际收益，正在超过单模型参数量的边际收益。这条线值得持续盯。

🗣️ 大佬观点

⚠️ Twitter / HuggingFace 等墙外源本机无代理暂未采集，以下观点来自 Hacker News 公开讨论与个人博客原文。
"Mathematics has changed. Let's act like it." — Terence Tao, Nov 1 2026
陶哲轩：数学已经变了，我们该按变化后的样子来做。核心意思是 AI 已经把"证明"和"猜想生成"的成本结构改了，数学界的评价体系需要跟着调整。
"LLM Voice" — Martin Fowler
Martin Fowler 谈"LLM 腔"：模型生成的文字有一种可识别的语体，写作者要警惕被这种语体同化。这条和老大平时要求的"去 AI 味"是同一件事。
"AI isn't replacing SREs, it's deskilling them" — Signoz
AI 不是替代运维工程师，而是在削弱他们的判断力。当故障由 AI 先判、人只做确认，人的独立诊断能力会退化。
"AI is overwhelming and I'm doing it wrong" — Ben's Bites
Ben's Bites 这次罕见了写了篇自我怀疑：工具太多、每天都在追，反而做不出东西。作者给的建议是砍掉一半订阅，只留真正每天用的两个。

🚀 今日可做项目

BuilderPulse

今日源无报告，给出三个可动手方向

1）Super-agent 精简复刻：用 DeepSeek 刚放出的 Router + Worker 思路，做一个只管两件事的最小版本——跨会话上下文保持 + 后台投机执行。一个人一周能跑通。
2）AI 版权合规扫描器：Claude 禁游戏复刻、游戏公司追责、巴西法院判例，三个信号指向同一个需求：判断一段生成代码/素材是否在复刻已有作品。可以先做"原创度体检"这种轻量产品。
3）多智能体组队基准：Memdoor 证明了小组队能打赢大模型，但缺一个公开的中文评测。把中文业务任务做成一套可复现的组队基准，本身就有传播价值。

这条你可能用得上：三个方向的共同点是"不需要 GPU、不需要融资，一个人 + Agent 就能出第一版"。
