📄 前沿论文

arXivFast Models, Slow Evidence：LLM Agent Harness 中系统一决策模型的配对自审计评估
Agent harness 每个任务要做许多小型类型化决策（选哪个模型、用哪个工具、检索文本是否相关、输入是否含注入）。本文评估「系统一」决策模型单次前向即答的可靠性与其证据链。
arXivDeReAct：分解式推理与行动，构建可靠 AI 智能体
现有 ReAct 用单一策略同时负责提议动作、与环境交互、判定任务完成，导致「动作授权」和「完成控制」难以独立约束。DeReAct 把三者解耦。
arXivChoosing Before Acting：长程工具调用智能体的比较式价值估计
长程工具调用里，最终结果奖励的信用分配很弱。本文提出比较式价值估计，让「选动作」先于「做动作」。
