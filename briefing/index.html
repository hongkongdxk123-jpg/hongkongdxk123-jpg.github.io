替代方向：给智能体用的基础设施正在变成独立赛道

① 给每个智能体一个邮箱（Botmail）——智能体之间用邮件异步协作，绕开会话和 API 额度限制；
② 跑智能体写的代码的沙箱（Plimsoll，自托管）——企业落地最缺的一环；
③ Claude Code 会话任务管理器（proc-stats）——把多个编码智能体当进程管；
④ 用自己声音朗读网站内容——Simon Willison 已跑通，旅拍站"听站"是个现成的差异化功能。
