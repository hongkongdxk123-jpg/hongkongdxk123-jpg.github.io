HN 60ptsOpenAI

量子位

📄 前沿论文
AutoIP：当 AI 让写证明变便宜之后，怎么保证“问题本身”没写错
arXiv 2611.06962
Lean 这类证明助手能把数学证明一路校验到公理，而 AI agent 让写形式化证明的成本骤降。问题随之而来：命题建模错了，证明再严也没意义。这篇工作提出 AutoIP 库，把经典线性正则化理论与泛函分析形式化，为逆问题建立可复用的形式化基座，并系统梳理了“可能性、陷阱与邀请”。
把“问题写对”变成可校验的一步，这是 AI 做数学能否真落地的前提。
弹性专家并行：给 MoE 强化学习后训练的算力空转找解
arXiv 2611.06984
RL 后训练现在是提升大模型能力的主战场，但生成训练响应是主要算力瓶颈：MoE 模型里，先做完的 worker 会空转等最慢的那批。论文提出弹性专家并行，把闲置算力动态重分配，在不增加卡数的前提下提高后训练吞吐。
省下来的都是真金白银。做后训练的团队可以直接看这篇的调度策略。
双账本模型：给跨云、跨模型的多智能体系统按笔算成本
arXiv 2611.06989
企业把业务跑在多智能体系统上，横跨多云、多个 LLM、编排层和记账系统，但财务只能拿到按 SKU 和计费周期聚合后的总数。论文提出“双账本”模型，把成本核算粒度下沉到单笔事务，让每个 agent 调用都能对应到具体业务动作。
多 agent 项目最容易失控的就是成本。这个思路对任何自建 agent 流水线都适用。
