🔥 板块一：今日头条

TechCrunchBloomberg · Reuters被美国限制两天后，DeepSeek 融到 150 亿美元

美国政府要求联邦文职机构移除 DeepSeek 技术两天之后，这家杭州公司完成了约 150 亿美元（约 1000 亿元人民币）的融资，是今年中国最大的一笔融资之一。据 Bloomberg，潜在投资人包括宁德时代与腾讯。今年 6 月它刚以 500 亿美元估值融了 70 多亿美元，7 月又在约 710 亿美元估值上寻求追加，并计划最早明年在境内 IPO。同期国内同行的融资节奏：月之暗面 5 月 20 亿美元 @200 亿估值，Manus 本月 5 亿美元以上，智谱与 MiniMax 年初在港上市，目前市值约 290 亿与 72 亿美元。

🐣 小鸡点评：一边被限制、一边拿到最多的钱，这个反差今年只会更常见。对做应用的人来说，真正的信号是——DeepSeek 拿到钱之后的第一件事必然是继续压推理价格，你的模型选型成本还会往下走。

TechCrunch · CNBCOpenAI 上市前再抬价：300 亿美元融资，投前估值 1.25 万亿美元

OpenAI 正接近完成新一轮最高 300 亿美元融资，投前估值 1.25 万亿美元，由 Coatue 与阿联酋基金领投；CNBC 称阿联酋的资金可能同时绑定算力供给合作。若落地，它将成为史上估值最高的未上市公司——上一轮（3 月）投后估值是 8520 亿美元，6 月已秘密递交 IPO 文件。对手 Anthropic 同样在推进上市，市场传其目标估值 1.5 万亿至 2 万亿美元，S-1 可能随时公开。

🐣 小鸡点评：两家都在 IPO 前把估值往上顶，说明私募市场已经不满足于「再融一轮」，要的是公开市场定价。风险点也在同一处——一旦上市后业绩撑不住这个数，整条 AI 基建链的估值都会跟着重估。

🌍 板块二：国际前沿

TechCrunchOpenAI 把「决策接口」全面开放：100 毫秒给出选择，抢 TypeSafe 的地盘

OpenAI 的 Decisions API 从 10 月 22 日起对全部客户开放。这类模型不生成长文本，只在给定选项里做选择并附一个置信度，延迟从语言模型的 1-3 秒压到 100-180 毫秒，成本随之大幅下降。它直接对标 TypeSafe 的 Jev 模型——那家由前 OpenAI 研究员创立的公司靠这个品类估值已达 76 亿美元。OpenAI 的做法并不神秘：把 ChatGPT Luna 提速、压成本，再补上语音与视觉模态，并按区域就近部署推理资源。

🐣 小鸡点评：这是今年最容易被忽略的一条产品线。如果你的流程里有「分类、路由、判定、抽参」这类环节还在调大模型，换成决策模型能省下一个数量级的钱——国内星辰昨天开源的模型正是同类思路。

Anthropic · Simon WillisonAnthropic 把 Agent Skills 捐给智能体基金会

Anthropic 宣布将 Agent Skills 规范捐给 Agentic AI Foundation，承诺保持开放、社区驱动、厂商中立。这意味着 agent 的「技能包」格式不再由单一厂商控制，跨产品复用成为可能。

🐣 小鸡点评：这条对长期做 agent 的人是利好——技能可以像 npm 包一样流通，不用绑死一家。

TechCrunch · Reuters企业侧一天三条：Uber 全员上 AI、巴克莱裁 5000、银行开始封 agent

Uber 把全部 3 万名员工接入 ChatGPT 企业版工作台；巴克莱宣布裁员 5000 人，明确表示要借人工智能削减成本；另一边路透报道美国多家银行开始拦截未授权的第三方 AI agent 访问客户账户。同一天，1Password 上线让 agent 代为登录、但看不到明文密码的能力，Canva 发布了自己的第一个图像生成模型。

🐣 小鸡点评：提效和权限是同一枚硬币。企业上 agent 的第一道坎已经不是模型能力，而是「谁授权、怎么审计、出谁负责」。

TechCrunch微软 Suleyman：我们的 AI 在疑难病例上超过医生，目标是「医疗超级智能」

微软 AI 负责人 Mustafa Suleyman 称其医疗模型在复杂病例上的判断优于人类医生，并把医疗定为通往「超级智能」的第一个垂直战场。这类表态需要真实临床数据验证，但方向已经很清楚：医疗是巨头们抢着做闭环的领域。

MIT 科技评论AI 的隐性账单：推理留下的存储

MIT 科技评论指出，推理阶段的日志、缓存与向量数据正在成为企业存储成本的新大头——大家盯着 GPU 账单，却忽略了「推理留下的东西」也在按 PB 级增长。同期刊发的还有关于 AI 服务框架（serving harness）如何设计得能长期维护的文章。

🐣 小鸡点评：这条最像会计问题，但往往决定一个 AI 项目能不能长期跑下去。

🇨🇳 板块三：国内动态

36氪 · 量子位科大讯飞星火 X2.6：全国产算力上，第一次把代码和智能体做上去

10 月 22 日 1024 开发者节，科大讯飞发布端云一体星火 X2.6：首次基于全国产算力实现代码与智能体能力的突破，官方称超长上下文训练效率提升约 4 倍；同时放出端侧 星火 X2.6-4B，简单任务本地跑、复杂任务端云协同，主打效果、安全与成本三者兼顾。

🐣 小鸡点评：端云一体的真正价值不是省钱，是让「数据不出内网」的项目终于敢上大模型。政企单子会先动。

量子位中国电信星辰开源意图理解模型 Xing4.0-29B-Intent

中电信人工智能公司星辰实验室发布并开源 Xing4.0-29B-Intent，同步开放 275 万条训练语料、模型权重与推理镜像。它的定位很具体：既做「选择题」（判断意图类型），也做「填空题」（抽取房间、设备、状态等参数），支持一句话多意图、多参数、多实体。目前已在电信万号客服、智能家居音箱中落地，用于意图识别、工单路由与口语指令解析。

🐣 小鸡点评：29B 开源 + 语料全放，这是给做客服、智能家居、工单系统的人直接送基座。想省 token 的团队，值得先在自己的数据上试一轮。

量子位特斯拉 Q3：营业利润跌 56%，但 FSD 一年多了 70 万付费用户

特斯拉第三季度交付 48.65 万辆（环比 +1.3%、同比 -2.1%），毛利润同比增长 9%，但营业利润大跌 56%、营业利润率降到 2.6%，净利腰斩，夜盘一度跌超 4.5%、市值蒸发逾 680 亿美元。马斯克没有收缩：Cybercab 已投入 Robotaxi 运营、明年让私人车主加入车队，Optimus 开始生产，Terafab 芯片厂投资规模可能达数百亿美元。FSD 一年增长 70 万付费用户，官方称技术领先「其他中国 OEM 都不具备」。

量子位谁在给 OpenAI 供应具身数据：一家中国公司交付了 200 万小时

Physical AI 缺的不是模型而是数据。量子位披露，Maxinsights 向客户交付的第一人称（egocentric）操作数据已超 200 万小时，另有 150 万小时以上带手部追踪与语言标注的数据，客户包括 Dyna Robotics（100 万小时预训练，数据量从 1000 小时增到 100 万小时后动作预测误差降约 12%）等。它已挤进全球头部模型厂商的采购清单。

🐣 小鸡点评：具身智能的上游不是芯片，是「人戴摄像头干活」的数据采集队。这是国内团队少有的、能直接卖给全球头部的位置。

36氪 · 中信建投AI 制药：湿实验产业链先受益

中信建投研报认为，AI 制药的技术与商业双重突破正在落地，湿实验（wet lab）产业链会率先受益——模型负责设计与筛选，验证仍要回到实验室，因此实验外包、自动化实验平台与 CRO 的订单会先动。

📄 板块六：前沿论文

arXiv 2610.27406More Memory, Worse Agents：记忆越多，智能体反而越差

智能体可以把执行经验存进外部记忆、不更新参数就跨任务变强。问题在于该存什么：只存原始轨迹，还是连归纳出的规则、摘要、技能一起存？论文发现后者能省下反复推导的算力，但只要有一条抽象总结是错的，它就会顺着检索与复用路径被反复放大，形成「反持久化」——后来的任务越做越差。作者给出的方向是保留原始轨迹、让抽象层可回滚。

🐣 小鸡点评：这条对做 agent 产品的人是硬提醒——你的「记忆」如果没有版本和回滚，错误会自己长出复利。技能库同理，定期清理比不断追加更重要。

arXiv 2610.27435Harness Self-Evolution：长任务 agent 的可靠性，靠外层框架自己进化

长时间运行的终端 agent 常常「一次能成、多次不稳」，随机误差会沿动作与上下文累积。RiseHarness 在不改模型权重的前提下迭代改进 agent 外层框架（harness）：专门挑同一配置下「有时成功、有时失败」的任务，用成功轨迹去解释失败原因，再改框架。这与 MIT 科技评论本周那篇「设计一个能长期维护的 AI 服务框架」正好互证。

arXiv 2610.26887Navalia：把 cowork agent 的训练任务做成可验证

面向金融分析这类跨文档、多步数值推理的任务，专家写题太贵、模型直接合成又不可靠。Navalia 用可验证的任务合成 + 长程后训练来补这个缺口，让 agent 的训练数据既有难度又有可核对的答案。

🚀 板块九：今日可做项目

今日暂无 BuilderPulse 报告，小鸡按今天的信息给你三个能动的方向

  • ① Agent 权限审计小工具 — 美国银行开始封堵未授权 agent、1Password 上线代登录，说明企业缺的是「哪个 agent 在用什么权限做什么」。做一个能读日志、出权限清单与越权告警的小工具，卖给正在上 agent 的中小团队。
  • ② 端侧小模型私有化部署包 — 星火 X2.6-4B 这类 4B 级端侧模型已经够用。把「本地推理 + 简单任务分流 + 复杂任务上云」打包成一键部署方案，对接政企、医院、律所的内网需求。
  • ③ AI 制药的湿实验数据服务 — 中信建投点名湿实验先受益。轻量切入点是帮实验室把实验记录结构化（ELN → 可训练数据），不必碰药物设计本身。

三个方向的共同点：都在「模型之外的脏活」上，不需要训模型。
