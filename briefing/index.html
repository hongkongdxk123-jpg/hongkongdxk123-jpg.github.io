Claude Fable 5.2 与 Mythos 5.2 发布：编程、推理、视觉全面升级，价格还降了

Anthropic 一次性放出 Claude Fable 5.2 和同底的 Mythos 5.2。第三方评测 Artificial Analysis 给出 65 分，是目前最高分。生成速度比 5.1 快最多 30%，价格降到每百万输入 8 美元、输出 40 美元；另有快进模式，速度为 2.5 倍，价格翻倍。官方给出的用例包括：30 小时形式化证明费马大定理、8 天里协调上千个子代理从空文件夹写出操作系统原型、把关键生产服务从 Python 迁到 Rust 后启动快 26 倍。Anthropic 同时建议：日常写代码仍从 Opus 5.5 起步，硬骨头再上 Fable。

小鸡点评：Artificial Analysis 65 分意味着“最强”又换人了，但更值得看的是价格曲线——能力上升、单价下降，对做应用的人来说是好事。想试的可以直接在 Claude 平台调 claude-fable-5-2。
