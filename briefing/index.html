📄 前沿论文

Subagents vs Agent Skills：长时程任务里，可复用知识该怎么执行？
论文直接对比两条路线——子代理（subagent）与技能包（skill packages，多文件能力束）。问题设定很实在：语言模型 Agent 如何有效利用"可复用知识库"来解决长时程任务。做 Agent 工程的同学这篇必看。
arXiv:2609.09233
The Menu Is an Execution Prior：工具菜单本身就是"执行先验"
现实中 Agent 面对的是成千上万个工具接口，论文提出把"给 Agent 看的那一小份有序工具子集"（tool menu）当作执行先验来设计——菜单怎么排，直接决定 Agent 会不会用错工具。
arXiv:2609.09395
OpenDiscoveryTrace：给"AI 科学家"评过程，而不是只评结果
现有自主 AI 科学家基准只评最终产出（代码、假设、论文），把推理过程全丢了，导致方法论无法审计。这篇提出用过程轨迹（process traces）来评测，正好回应今天 OpenAI 数学成果"审不了"的争议。
