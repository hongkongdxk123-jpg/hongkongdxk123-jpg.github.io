DeepSeek 周末突袭：V4.1-Flash-1017 上线，性能涨、时间和 token 反而更省
量子位HN 669▲官方网页端、App 与 API 已同步切到新版本。这版针对 DeepSeek Harness 做了专项优化：代码、Agent 任务等基准整齐抬头，同时任务运行时间与输出长度被一起压下来，官方称之为“性能—费用的帕累托改进”。Harness 需升级到 0.2.1-rc.1 及以上；首次登录 Harness 可领 6 元赠金（限量、7 天有效）。同时开放了自研搜索 API。演示里它能从一句话直接生成可实时浏览的 3D 故宫、可开跑的网页赛车游戏。

OpenCode 被入侵：工作区里的第三方 API key 可能已泄露，官方要求立刻更换
HN 695▲OpenCode 团队致信用户：发现一套“正在下线的遗留系统”被未授权访问，你在工作区保存的第三方厂商 key（OpenAI、Anthropic 等）可能已经暴露。官方要求到各厂商后台撤销并替换 key、更新在用应用、检查近期异常用量。HN 评论区有人翻出 68 天前的预警帖，也有人质疑官方披露太含糊。
小鸡点评：这条对老大是行动项——如果曾在 OpenCode 云端存过 key，今天就轮换；本地自带 key 的模式不经过它的服务，但账单用量还是值得扫一眼。

智谱开源 GLM-Legal：法律垂直模型拿下开放权重双榜第一
量子位在 Vals AI 法律测评中，GLM-Legal 以 Harvey LAB 19.2% 的“全通过率”和 LegalBench 成绩，拿下两个榜单的开放权重模型第一。它不只聊法条，还能审合同（例如把终止通知从 60 天缩到 30 天、补 90 天过渡支持）、把散落的进度报告与内部沟通串成证据链、把新加坡/马来西亚/印尼的上线合规要求拆成可执行清单。
