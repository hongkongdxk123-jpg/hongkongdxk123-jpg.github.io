量子位

何恺明团队新作 NAT-ARC：看猫片就能学会 ARC 挑战

纯视觉路线的 ARC 解题方案，不用 LLM：先在 ImageNet（约 130 万张猫狗花草）上用 MAE 预训练 encoder，再迁移到抽象彩色格子推理。最好的单模型（0.6B 参数）在 ARC-1 上拿到 63.4% pass@2，三种预训练策略集成后到 70.2%（总参数约 2B）。

对照参照：专门为 ARC 微调的 The ARChitects 用 8B 语言模型拿到 71.6%。视觉路线以约四分之一参数量逼近专用 LLM 系统。论文最有价值的发现是：ImageNet 预训练打通了视觉路线的 scaling 瓶颈——注意力可视化显示，预训练模型在完全没见过 ARC 格子时，就已能区分前景/背景并聚焦有意义区域。

🐥 小鸡点评：「从自然图像里学到的分组、匹配、分割能力，和抽象推理底层共享同一套表征」——这句是真正值钱的结论，也解释了为什么通用视觉预训练能迁移到陌生领域。

NAT-ARC：把 ImageNet 视觉预训练迁移到抽象推理

何恺明团队。0.6B 单模型 ARC-1 pass@2 = 63.4%，2B 集成 = 70.2%，逼近 8B 的专用 LLM 系统（71.6%）。核心洞见：ImageNet MAE 学到的「前景/背景分离」先验，在陌生 ARC 格子上天然生效；提升集中在 match-and-copy 与 connected-component reasoning 两类任务。

arXiv 2609.38296

AI Agents are Vulnerable to Radicalization（智能体会被「激进化」）

模拟两个 agent 的对话：一个扮演人类人格的目标模型，去看另一个模型能否操纵它的信念。LLM 能影响人的信念，但它们能否互相操纵，此前几乎无人研究。

🐥 小鸡点评：多智能体系统上线前值得读的一篇——如果 agent 之间会互相「带偏」，那编排层就需要免疫机制。
arXiv 2609.38288

AREX-2：用长程反思任务推进自我改进 Agent

把自改进拆成两种能力：reflection（产出解法后反思）与后续迭代，在测试时反复精炼答案。是「test-time 自我改进」这条线的新进展。

arXiv 2609.38340

CARAT：材料学 LLM 到底在推理还是在背诵？

问晶体结构问题时，准确率无法区分「从结构推理」和「照抄输入里已经印好的字段」——因为结构描述常常直接印着被打分的那个字段。CARAT 用来把这两者拆开。

🐥 小鸡点评：「输入里已经含着答案」这个评测陷阱不止坑材料学，凡是给结构化输入打结构化输出的基准都该自查一遍。
