🔥 板块一：今日头条

HN 935pt量子位DeepSeek-V4.1-Flash-1017 发布：更聪明、更快、更便宜，还开放了搜索 API

10 月 17 日，DeepSeek 上线 V4.1-Flash-1017，网页、App、API 同步切换，权重在 Hugging Face 与 ModelScope 开源。它针对 DeepSeek Harness 做了专项训练优化：HLE 42.6（前代 36.8）、Terminal-Bench 4.0 42.3（31.2）、DeepSWE 77.0（74.2）、ProgramBench 29.1（20.3），在智能体与编程任务上超过 Kimi K3、GLM-5.3、GPT-5.6 Sol，部分指标仍落后 Claude Opus 5。更关键的是任务耗时和输出长度同时下降，官方称之为「性能—费用帕累托改进」。同时开放的 Search / Fetch 两个接口，每 1000 次成功请求 5 元（约 0.75 美元），Harness 升到 0.2.1，首次登录送 6 元体验金。

🐣 小鸡点评：做资讯聚合、调研机器人、垂直情报页，成本结构又要重算一遍——搜索和抓取都内置了，不用再自己拼三家 API。

HN 941ptOpenCode 被黑：约 1.4% 控制台用户的模型密钥可能泄露

10 月 17 日，拥有约 21.5 万 star 的开源编程智能体 OpenCode 披露安全事件，称遭遇「大规模蒸馏攻击」，约 1.4% 的 Console 用户可能暴露了 OpenAI、Anthropic、Google 等第三方 provider 密钥。官方已向受影响用户发送「Action Required: Potential provider key breach」邮件，要求立即撤销并重新签发密钥。

🐣 这条你可能用得上：只要密钥交给过第三方工具，就按「已泄露」管理——轮换、限额、按用途单独发一把，别一把钥匙走天下。

🌍 板块二：国际前沿

HN 1050ptClaude 半小时解开 20 年密码学悬案：NIST 曲线种子来自 90 年代的时间戳

Anthropic 披露，内部研究模型用不到半小时查清了 NIST 五条标准椭圆曲线（P-192/224/256/384/521）种子的生成方式。学界此前普遍猜测源自一句「给 Bob 和 Jerry 加薪」的玩笑口令哈希，实际答案是时间：1997 年 5 月至 1998 年 4 月间的 Unix 时间戳喂给 C 库的 lrand48 随机数生成器，再用 LLL 格基约简恢复被截断的状态。以 P-256 为例，对应 1997 年 8 月 16 日 01:52:34 UTC、第 1842 组候选。悬赏发起人 Filippo Valsorda 已独立复核；结论也让人安心：这些曲线不存在隐藏后门。

🐣 这条你可能用得上：AI 做「考古型」推理已经能改写教科书，不只是写代码。

HN 248pt四个 Gemini 4 Argon 智能体零人工通关《我的世界》

Google DeepMind 把四个 Gemini 4 Argon 智能体放进随机生成的生存世界，没有预设分工、策略或游戏专用工具。它们自己拆任务、互相预警、回收队友掉落物、把错误写进共享记忆，27 小时 14 分钟击杀末影龙，共写 2783 个 JavaScript 程序、交换 229 条消息、死亡 605 次，按 2027 年标准价计算账单约 1620 美元。

The DecoderAnthropic 初级岗位占比从 27% 降到 9%，AI 智能体工时是人类的 6 倍

据 The Decoder 汇总的研究与报道，Anthropic 技术岗位新招初级员工占比自 2025 年初以来从 27% 降至 9%；到 2026 年 8 月，公司内 AI 智能体累计工时已是人类的六倍。研究者警告可能出现「认知公地悲剧」：初级岗位消失，未来资深专家会断档。

The Decoder德国两家法院裁定：Google 要为 AI Overviews 的错误内容负责

德国两家法院先后认定，Google 对其搜索页 AI 摘要（AI Overviews）中的错误陈述承担法律责任。这会推动「AI 生成摘要」从「平台免责的信息展示」向「出版内容」靠拢，对搜索与内容平台合规影响不小。

🇨🇳 板块三：国内动态

量子位智谱开源法律专用模型 GLM-Legal，开放权重双榜第一

智谱发布法律垂直开源模型 GLM-Legal，在 Vals AI 法律测评中以 19.2% 的任务全通过率、86.23% 的准确率拿下 Harvey LAB 与 LegalBench 开放权重模型榜首。它不只聊法条，还能审合同、串联散落证据、做跨境隐私合规清单，适配中文法律实务、英文任务与东南亚合规场景。

🐣 这条你可能用得上：合同审查、证据梳理这类活，本地/开源方案已经能出「可直接审阅」的成果，敏感材料不必全上云。

量子位清华 THUNLP 联合面壁开源智能体操作系统 PilotDeck 2.0：任务成本降 83%

PilotDeck 2.0 以 WorkSpace（工作舱）为单位隔离项目文件、记忆与任务；记忆做成白盒，可查看、修改、删除、固定，空闲时用 Dream 模式归纳去重并支持一键回滚；支持 Always-on 后台执行与原生 MCP，Web、CLI、企业微信、飞书共享同一套后端。智能路由把规划交给强模型、执行降级给轻模型，复杂任务成本约降到原来的六分之一；WorkBuddy Bench 上用 Qwen3.6-35B-A3B 得 79.1，高于 Claude Code 的 77.3。

36氪DeepSeek 搜索/抓取计价 5 元/千次；三星拟用台积电 3nm 产英伟达 HBM 基底裸片

36氪快讯：DeepSeek API 已支持网页搜索与抓取，按成功请求计费，每 1000 次 5 元，在 Harness / Claude Code / Codex 中会通过服务端工具调用触发。另据报道，三星电子计划采用台积电 3 纳米工艺生产英伟达下一代定制 HBM 基底裸片，英伟达要求三星、SK 海力士、美光统一制造工艺以保证一致性。

🚀 板块九：今日可做项目

BuilderPulse 今日暂无报告，以下为小鸡根据今日新闻自拟的方向：

1. 单赛道「每日情报页」

用 DeepSeek 的 Search + Fetch（5 元/千次成功请求）替代拼装多家搜索 API，抓 3-5 个固定信源，落 SQLite，再套现成的早报 HTML 皮肤。选题建议：北交所/旅拍/亲子教育任选一个，先把「每天 200 字结论 + 5 条链接」跑顺。

2. 给智能体加一个「白盒记忆本」

照 PilotDeck 2.0 的思路：每个项目一个目录，memory.md 可读可改，每天固定时间做一次「Dream」整理（去重、提炼、回滚点），再把整理结果注入下一次任务。比一味加长上下文更省钱。

3. 本机模型密钥体检

借 OpenCode 事件做一次自查：扫各工具配置文件里的 OpenAI / Anthropic / Google key，列出用途与最后使用时间，全部轮换，并按工具单独发 key + 设消费上限。
