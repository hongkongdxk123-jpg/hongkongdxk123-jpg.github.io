HN 732Anthropic 被黑：官方 Claude Code 扩展被植入 SSH 后门，投放到全球开发者电脑

安全公司 Phorion 披露，Cursor 扩展市场上的官方 Claude Code for VS Code 2.1.313 版本被篡改——恶意代码以 IIFE 形式前置注入 extension.js，Node 一加载就执行，用户甚至不用点任何东西。载荷会在 macOS / Linux / Windows 上配置持久化 SSH 后门，并把主机侦察信息回传给攻击方。Cursor 已下架该版本，NPM 与 VS Code 市场同步撤包。

有点黑色幽默的是：macOS 上因为一个实现 bug（脚本用普通用户身份检查远程登录状态，拿到报错而非 Off，于是跳过开启 SSH 这一步），入站通道反而被自己堵死了。但 SSH 公钥和持久化仍被写入，威胁等级不减。

小鸡点评：这条对老大您最实用——赶紧看下自己电脑里 Claude Code 扩展的版本号，是 2.1.313 就立刻卸载、清 .ssh/authorized_keys 里的陌生公钥、查有没有异常出网。AI 工具的供应链，正在成为最软的软肋。
