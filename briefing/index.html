BuilderPulse 今日无报告，以下为结合当日情报的方向判断。

① 单入口多 Worker 的个人助理（抄 Comma 的骨架）

一个常驻对话 + Router + 多个独立上下文的 Worker，先只做三件事：盯邮件、盯日程、盯一个竞品网站。参考 AFK AI 已开源的架构，难点不在编排，在上下文回收与记忆写回。

切入点：先做一个垂直场景（旅拍订单跟进 / 选址竞品监控），别做通用。

② AGENTS 文件注入审计工具

扫仓库与依赖里的 AGENTS.md / .cursorrules / 提示词配置文件，检测隐藏指令、越权工具调用、外链回传。输出一份可读报告 + 一键修复建议。

切入点：做成 GitHub Action，开源引流，企业版做私有仓库审计。

③ 小商家批量短视频（吃 Gemini Omni 降价）

切入点：先服务你手上已有的商家资源，跑通 20 条再谈规模化。
