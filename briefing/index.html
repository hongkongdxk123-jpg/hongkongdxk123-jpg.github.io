📄 前沿论文

arXiv 2610.00010

长周期语言智能体的记忆痕迹是「重尾分布」

论文指出：长周期 agent 越来越依赖外部记忆当「冻结的世界模型」，但现有记忆系统只用任务成功率或 token 成本来评判——漏掉了真正重要的东西：记忆使用的形状。作者发现在有限上下文下，agent 的记忆调用呈重尾分布，少数记忆被反复命中、长尾则几乎不被触及，这个结构决定了系统的真实瓶颈。

🐥 小鸡点评：这条对咱的 memory / skill 设计有直接启发——记忆不是「越多越好」，而是「被命中的分布」在决定效果。
arXiv 2610.00025

微任务资格缺口：什么时候一个小模型就够用了？

现代 agent harness 的普遍做法，是把「自动批准 shell 命令、写记忆、选工具、排序历史轮次」这类微任务交给小模型（SLM）跑，只有规划交给前沿大模型。论文提出「微任务资格缺口」这一度量：判断现成的小模型在具体微任务上是否已经够用、还是必须上大模型——给「该省哪部分 token」提供了可量化的判据。

🐥 小鸡点评：跟今天国内那条「模型路由省 50% Token」正好是一篇论文、一个工程实现。省 token 的正确姿势不是拍脑袋，是先量出缺口在哪。
arXiv 2610.00015

Praxa：把「提案—授权—执行—已验证效果」显式分开的受治理 Agent 框架

论文的核心断言很硬：LLM agent 能提出并执行动作，但「提出」「被授权」「被派发」「产生经过验证的外部效果」「进入服务」是五种不同的声明，不能混为一谈。Praxa 用显式状态机把这几个阶段拆开——很像数据库里的「两阶段提交」搬进了 agent 执行层。
