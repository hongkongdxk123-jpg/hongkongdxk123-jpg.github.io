📄 板块六：前沿论文

arXivPistis Technical Report：27B / 9B 多模态模型家族
基于 Qwen3.6 与 Qwen3.5 构建的 27B 与 9B 多模态大模型，走一套通用、可扩展的「后训练」框架。对关注开源多模态落地的人来说，这是本周最实用的一篇——底座、尺寸、路径都写清楚了。
arXivPAWS：政策驱动的智能体世界模拟
把政策干预在公共沟通、机构决策、利益相关方反应中的传导过程，与时间对齐的历史证据连起来，用于金融多智能体仿真。做「政策 / 事件 → 市场反应」这类推演的人可以直接借鉴其数据结构。
arXivDEEPO：双熵增强策略优化，抑制多模态模型幻觉
作者把强化学习对幻觉的「效果不均匀」归因到从奖励到参数更新的纠错链上两个薄弱点，用双熵机制补偿。逻辑清晰，属于能直接接到现有 RLHF 流程上的改进。
arXivTWIST：对话记忆的「干预质量」基准
长对话记忆的评测长期以来只看「能不能回忆」和「能不能按提示更新」，TWIST 提出要测第三个维度：干预的质量——即系统在什么时机、以什么方式改写记忆。做过记忆型 Agent 的人会知道这个缺口在哪。
arXiv对抗式闭环课程：让角色扮演智能体持续进化
现有 RL 方法通常在固定的场景池上训练，模型一进化、场景就过时。这篇用闭环对抗的方式持续生成新场景，思路与自我对弈同源。
