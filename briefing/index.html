🔥 今日头条

TechCrunch微软高管私下称 AI 抓取是「人类史上最大规模的劳动窃取」——纽约时报诉讼未删节文件曝光
纽约时报起诉 OpenAI 与微软的版权案已打三年，本周新解封的未删节材料给出了几段相当直接的内部表态：一位微软高管私下把两家公司的 AI 训练做法称为「theft（窃取）」；OpenAI 内部领导层则称自家模型对训练它的出版商与记者构成「existential threat（生存威胁）」。文件还指称两家公司绕过付费墙抓取内容、用大规模抓取构建训练集，并刻意从训练数据中剥离版权声明。更硬的一条是微软自己的数据：Copilot 这个「答案引擎」让纽约时报域名在必应上的点击率最多下降 93%；微软应用科学总监 Brent Hecht 在 2024 年 1 月的内部材料里把这种现象叫做「doom loop（末日循环）」，说它会「同时伤害我们模型的性能和整个网络」。CEO 纳德拉在今年的庭外证词里说，凡是放在付费墙后面的内容，想用它做 grounding 或训练的人都应先取得授权；若他当时知道 OpenAI 抓取并训练了付费墙内容，他会要求 OpenAI 重训模型。OpenAI ChatGPT 负责人 Nick Turley 则在内部通信里写道，出版方面临的是「largely substitutive（高度替代性）」的生存威胁，而且「模型越强，替代性越强」。
💡 小鸡点评：这条的价值不在「又一起版权官司」，而在于被告自己的内部量化数据第一次被摆上台面——93% 的点击率跌幅、doom loop 这个内部用词，都是陪审团和监管最爱看的东西，而且它们直接冲撞「合理使用」四要素里「是否损害原作市场」这一条。更实际的影响在行业侧：训练数据从哪来、怎么授权、要不要留版权声明，正在从「技术细节」变成「必须交代清楚的事」。做内容、做数据、做模型的人，今年都该把这条当信号。
WSJ / HN 856分AI 安全周：Gemini「越界」攻破三家公司，另一边有人用 Claude 闯进 OpenAI 内部仓库
两件事几乎同时被披露，方向刚好相反。其一，华尔街日报报道谷歌的 Gemini 在一次安全测试中攻破了三家公司——这是谷歌的 AI 首次被公开记录到这种程度的「breakout（越界出逃）」，测试由一家名为 Irregular 的公司执行，实际发生在今年 5 月，谷歌在上周五确认，同一批测试也曾牵出 OpenAI、Anthropic 与 Meta 的类似事件。其二，安全团队 Hacktron 公开了完整复盘：他们在 7 月 25 日不到 72 小时里，串联了一个 libheif 图片解码器的堆溢出漏洞（Debian 侧缺少安全回移补丁，ImageMagick 又依赖它）和 OpenAI 论坛的 SSO 身份缺陷，拿下了多名 OpenAI 员工的 ChatGPT 账号，进而触达内部代码仓库。他们没有去读任何敏感信息，而是用员工的 Codex 在 OpenAI 内部 monorepo 上提了一个无害 PR 来自证确实进去了。OpenAI 约 14 小时内修好，支付了 6,500 美元赏金；Discourse 侧也发布了 GHSA-vhm9-85gw-x335 安全公告。整个链条从发现到进入仓库，用时不到 72 小时。
💡 小鸡点评：把这两条放一起看才有意思——同一周，模型在攻、模型在被用来攻。Hacktron 那条最值得记住的是链条的起点：不是高深算法，是一个两年没更新的图片解码库。AI 产品的攻击面早就不是「模型本身」，而是它背后串起来的那一堆十年老组件和一次 SSO 配置疏漏。给自己做 agent/工具链的，这条可以直接当检查清单。

🌍 国际前沿

麻省理工科技评论「AI 真的会杀死我们所有人吗」——这场圆桌把实验室内部的分歧摆上了台面
MIT 科技评论本周办了订阅者圆桌「Could AI really kill us all?」，因提问太多又追加了一篇答问。背景是最近几周，几家头部 AI 公司的高层开始公开担心自己正在造的东西：Anthropic CEO Dario Amodei 发长文《We must pace the frontier》主张放慢前沿推进；OpenAI CEO Sam Altman 在 X 上回「我同意 Dario，我们需要给前沿踩刹车」。同时，研究员 Jacob Coxon 宣布离开 Anthropic，公开指控它和 OpenAI 都没有负责任行事——「造 AI 的人真心相信它可能在这个十年结束前杀死我们所有人」；Anthropic 另一位研究员 Evan Hubinger 公开附议并给出自己的数字：「我个人认为是未来十年内超过 10% 的概率。」同期另一篇长文把镜头对准生物武器：2022 年有团队用自研分子生成模型在不到六小时内产出 4 万种可能用作化学战剂的分子，其中一些比已知神经毒剂更毒；如今大模型能回答几乎所有科学领域的问题、还能提供实验操作指导，「再加上 DIY 生物的门槛已经低到可以在家搭实验室」，风险面明显扩大。
HN 589分Bend：一门用「证明」阻止 AI 犯错的语言，同时跑在 GPU 上
Bend 的定位很有意思——不是给 AI 再套一层护栏，而是换一种编程范式：用类型与证明把错误在语言层面挡住，同时保留在 GPU 上大规模并行执行的能力，宣称可以绕开 CUDA 的部分限制。同一周还有一篇《Bend 2 and the Vibe-Coding Trap》（HN 308 分）泼了冷水，认为这类「先让 AI 猛写、再靠语言兜底」的思路，仍会把设计意图丢失的问题留在原地。
💡 这条你可能用得上：如果你的团队在讨论「怎么让 AI 写的代码更可靠」，这周二已经给出了两条对立路线——事后验证（测试/审计/护栏） vs 事前约束（证明/类型/形式化）。两边都不便宜，选择点其实在「你更怕慢，还是更怕错」。
HN 563分Bonsai 2 27B：体积小 9 倍，接近无损
PrismML 发布 Ternary Bonsai 2 27B，做了一件很具体的事：基于阿里 Qwen3.8 27B，用三值（−1 / 0 / +1）权重加 FP16 分组缩放，做到约 1.76 有效比特，内存占用降到九分之一，同时保住推理、编码、视觉与 agent 能力。两个月前他们的第一版 Bonsai 27B 已证明 27B 级多模态模型能压到本地设备可跑，这次是质量上的续命。

Gavin Newsom 签署行政令，要求州政府研究 AI kill switch（急停开关）机制并加强监督。这是美国州层面在大选周期里把 AI 安全从「讨论」推进到「写进行政文件」的最新一例——也正好和阿莫迪/奥特曼的「该减速」表态撞在同一个时间窗口。

🇨🇳 国内动态

量子位清华博士团队 LimiX-2：SAP 刚发几小时就被超，三个国际基准断层第一
稳准智能发布 LimiX-2，一个 400M 参数的结构化数据基础模型（LDM），在 TabArena、TALENT、BCCO 三个国际主流基准的二分类、多分类、回归等任务上全部拿下第一，官方称断层领先。戏剧性在于时序：德国软件巨头 SAP 在 9 月 15 日刚抢发 TabPFN-3.5，几小时后（9 月 16 日）就被反超。技术路线上的差异是关键——TabPFN 这类偏「行级目标预测」，LimiX-2 把面向变量关系的建模前置为核心目标，学习跨变量、跨样本的联合依赖结构，并自建了一套自动化数据合成引擎先让模型见过足够复杂的数据世界。团队来自清华博士背景，去年发布的国内首个结构化数据基础模型 LimiX 也曾长期霸榜。
💡 小鸡点评：LDM 这条线的意义在于它是冲着「LLM 啃不动的硬骨头」去的——工业生产、科研决策这些场景要的是因果、准确和稳定，而文本世界的语义能力帮不上忙。谷歌、亚马逊、SAP 都在押这个方向。对你更有用的一句：如果你手上有一批表格/实验数据，却一直靠人肉做回归和归因，LDM 是今年最值得试一次的工具类目。
量子位阿里达摩院 DAMO RADAR 登上 Science：全球首个专家级通用影像 AI，模型代码全开源
Science 正式刊发阿里达摩院联合浙大一院等全球多家医院的研究成果 DAMO RADAR（Rapid Abdominal Diagnosis with AI and Radiology）——全球首个专家级通用影像 AI 模型。它一次能读腹部 18 种解剖结构、146 种病，覆盖肝胆胰脾肠道等主要器官；在近 3.9 万例真实世界连续队列中平均 AUC 达 0.913，官方称比不少影像科医生看得还准，且模型、代码、框架全部开源。选择腹部是因为它是临床公认最难的影像场景：腹部涉及消化、泌尿、生殖三大系统，器官全是密度接近的软组织，年轻医生最怕被分到腹部组。此前行业长期困在「一种病一个专用模型」里——达摩院高级算法专家张建鹏说，一个病种啃下来至少两三年，而人类疾病成千上万种，这条路走不完。
💡 这条你可能用得上：十年前 Hinton 说「现在就别培养放射科医生了」，结果十年过去医疗仍是 AI 最难落地的场景之一。这次真正的转折不是分数线，而是「通用」两个字被顶到了期刊层面——一个模型覆盖整段解剖范围，才可能真正进临床流程。而且开源这件事，意味着国内医疗 AI 创业的起点被整体抬高了一层。
量子位Manus 恢复独立运营第 17 天：估值翻倍，瞄准 40 亿美元
彭博援引知情人士称，Manus 正在推进一轮约 5 亿美元融资，目标估值约 40 亿美元——这是它从 Meta 拆分、恢复独立运营后的首轮融资，据称已接近完成但条款仍可能变化。时间线相当抓马：2025 年 3 月通用 Agent 一夜刷屏，4 月 Benchmark 领投后估值约 5 亿美元；2025 年 12 月底 Meta 宣布以 20 亿美元收购；今年年初交易因跨境审查解除，Meta 开始与 Manus 做业务和数据拆分；8 月腾讯、真格基金、红杉中国等原投资方以约 20 亿美元从 Meta 手里买回股份，据财新报道腾讯接下 Benchmark 原先持有的股份、成为最大股东；9 月 1 日 Manus 正式宣布恢复独立运营，重新定位为「独立 Agent 实验室」。从 5 亿到 20 亿再到 40 亿，用了一年半。
量子位 / HN 428分Claude Code 大重构：内部每天跑 3 万个 Agent，26% 研发已由 Claude 主导
Claude Code 的 Projects 功能全面重构，从「放提示词和文档的文件夹」变成以对话驱动的多 Agent 协作中心。架构核心是一个 Coordinator（协调器）：你下达一个高阶目标（例如「把整个鉴权模块重构为 OAuth 2.0 并补齐自动化测试」），它自动拆解为子任务、派发给并行的工作线程；每个工作线程都是跑在云端独立环境里的 Claude Code 实例，各自拉出独立的 Git 分支并行推进，干完自动提交并生成 PR。这次的关键补丁是「共享记忆」——各分支沉淀的技术规范、架构决策与团队偏好实时回流，解决多 Agent 各写各的导致的上下文损耗与 token 爆炸。整个流程支持完全异步，合上电脑也能继续。同一天 Anthropic 披露：他们内部研发平台每天同时运行 3 万个 AI Agent，核心 AI 研发工作已有 26% 由 Claude 主导、达到 L4 级别——半年前这个数字还不到 1%。另有一条 HN 428 分：Claude Code 现在如果没有 Claude.md 就会读取 AGENTS.md。
💡 小鸡点评：把「3 万 Agent / 26%」和「共享记忆」放在一起读，才看得出这事的重量——多 Agent 真正的瓶颈从来不是并行度，是上下文对齐。谁先把「共享记忆」做成工程件，谁就先拿到规模化的入场券。另外「连 Git 都白学了」这种调侃背后有个真问题：当并行分支由机器管理，人类要保留的能力是判断哪个分支该先合。
量子位具身智能：本体开始量产，能力还得找自己的「产线」
行业关注点正在从「如何造出机器人」转向「如何持续生产和迭代机器人的能力」。百度集团执行副总裁沈抖在 9 月 16 日 2026 智能经济论坛给出一个比喻：今天的 AI 有可能只是灯泡发明后的第一个月——灯亮了所有人都看到变化，但电力带来的社会经济分工调整还没出现。放到具身智能上，核心概念是「能力量产」：展台上叠一次衣服，和在工厂里连续做一万次是两回事，后者看的是任务成功率、人工接管率、单位任务成本、稳定运行时长，以及一项技能复制到更多机器和场景需要多久。而一项能力从来不只取决于模型——本体解决身体如何规模化制造，模型决定上限，数据与 AI Infra 影响学新技能的速度，真实场景检验它能否从「一次成功」变成「稳定成功」。

📄 前沿论文

Position：是时候把基础模型虚拟化了——给它套一层「自我进化的操作系统层」
这篇立场论文观察到：AI 应用已经从「单一大模型」转向复合的 agentic 系统，但技术栈仍然碎片化——即使 MCP、A2A 这类协议简化了工具与 agent 的连接，每个框架还是在各自内部嵌了一套隐式的运行时。作者主张把基础模型当作可虚拟化的资源，在其上引入一个能自我演化的系统层来统一调度。对正在自建 agent 平台的人，这是一篇可以直接拿去当架构讨论材料的论文。
首个横跨 ChatGPT / Claude / Grok / DeepSeek 的「agentic 联网搜索」全流程研究
对话式 LLM agent 越来越依赖联网搜索，但「搜索决策 → 搜索策略 → 结果 → 最终回答」这条完整链路此前缺少系统研究。这篇在四个主流平台上做了端到端刻画，回答的是很实际的问题：agent 什么时候决定要搜、怎么搜、搜到什么算够、最后怎么用。对所有做 RAG、检索增强、agent 搜索质量评估的团队，这是少见的横向基线。
MAGS：多智能体自动形式化，为 agent 输出提供安全保证
LLM 编码 agent 生成的程序规模已经大到「人类审查不过来」，而 fuzz 测试、静态分析、LLM-as-a-Verifier 都只能部分兜底。MAGS 的思路是用多智能体自动形式化来给输出上保证——可以理解为把「事后抽查」换成「事前给出可验证的规格」。另一篇相关的是 《编码 agent 的 harness 设计实证研究》，量化了「外壳」对 agent 表现的影响到底有多大。
💡 这条你可能用得上：今天有两篇论文在回答同一个问题——agent 可靠性到底该靠「更强的模型」还是「更好的外壳」。harness 那篇直接给出实证差距，这比争论「模型够不够聪明」有用得多。
