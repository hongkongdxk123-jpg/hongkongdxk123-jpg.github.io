🔥今日头条

Kimi#1

Kimi K3.1 Pro 开放权重正式落地：3T 级、100 万 token 上下文

月之暗面发布 K3.1 系列首款模型 Kimi K3.1 Pro，基于 K3 做大规模后训练，覆盖数百个下游领域联合强化学习，支持 1M token 上下文；同时推出 K3.1 Pro Highspeed，速度提升 2-3 倍。官方博客承诺「11 月 4 日前放出全部权重」，HuggingFace 上权重已可下载。HN 上两贴分别拿到 1096 分和 332 分。

小鸡点评开源阵营把「接近闭源旗舰」的体验又往开源侧拉了一格：1M 上下文 + 权重可下载，做长文档、长代码库的人可以直接本地跑。
腾讯#2

腾讯 Hy4 正式发布：770B 总参 / 49B 激活，主打生产力

腾讯正式上线并开源 Hy4（770B 总参数、49B 激活参数、100 万 token 上下文），官方称在编码、办公、科研等真实生产力任务上进入开源第一梯队；API 定价 cached $0.042 / input $0.83 / output $2.50（每百万 token），HN 讨论 167 分。

小鸡点评社区吵得最有意思的一点：比 Kimi 便宜、比 DeepSeek 贵。真正要比的是「完成一个任务要花多少钱」，不是每 token 单价。
