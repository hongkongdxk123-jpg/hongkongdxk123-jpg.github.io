Anthropic

Claude Opus 5.5 发布：对标 Fable 5.1，成本降 40%，登顶最强模型

9月22日，Anthropic 推出 Claude 5.5 家族首个模型 Opus 5.5。大多数工作上追平 Claude Fable 5.1，运行成本比 Opus 5 低 40%：输入/输出 $4 / $20 每百万 tokens（降 20%），缓存读取 $0.20（降 60%），输出速度提升 30%以上。它是 Anthropic 提出「pacing the frontier（放缓前沿）」后的首个发布，经 Frontier Design、METR 等外部机构测试；行为对齐审计得分史上最高，更不易执行难以逆转的操作、抗提示注入更强。因在生物与网络安全领域能力接近 Mythos 5.1，采取类似 Fable 5.1 的护栏：网络安全类请求改路由到 Opus 4.8，生物类路由到 Opus 5。同时带上「保留思考」反蒸馏机制与 EU AI Act 水印，不再允许关闭思考模式。Sonnet 5.5 / Haiku 5.5 数周内跟进。

🐤 小鸡点评：Artificial Analysis 智能指数给到 58，直接登顶。缓存读取降 60% 这一条对天天跑 Agent 的人最实惠——长会话成本大头就在缓存。评测原文
OpenAI

同日出手：GPT-6 Sol 和 Luna 发布，API 价格直接腰斩

OpenAI 在 GPT-6 Astra 之后补上两个「性价比」型号。Sol 由 $4/$20 降到 $2/$10，Luna 由 $0.20/$1.20 降到 $0.10/$0.50，均降 50%。AutomationBench 上 Sol（xhigh）超过 Claude Opus 5（max），而每任务成本只有后者的 9%；AA-Omniscience 幻觉率从 92% 砍到 60%，编码智能体指数 57（+2）。代价是知识工作类评测：GDPval-AA 掉约 100 Elo、Luna 在 AA-Briefcase 掉约 45 Elo——主要输在交付物的呈现质量与要点完整性。GPT-6 Astra 仍是最强。

🐤 小鸡点评：同一天两家头部同时降价，说明「前沿能力」开始转为「前沿成本效率」的竞争，日常任务用便宜型号的甜点区正在变宽。

📄 前沿论文

arXiv 2609.20971

RBS-Attention：半径受限的稀疏预填充

长上下文推理的瓶颈在 prefill——密集自注意力必须先吃完整个提示。稀疏块选择能降本，但「块中心」可能掩盖块内真正相关的 token。本文用半径受限的稀疏选择把这块补上。

arXiv 2609.21096

从注意力图的拓扑特征识别幻觉

用注意力图的信息流动拓扑来区分「幻觉」与「非幻觉」回答，借助 Forman-Ricci 曲率识别信息共享受损的结构模式。给「什么时候模型在胡说」提供了一个不依赖外部标注的信号。

🐤 小鸡点评：如果能做成在线探针，做 Agent 可靠性的人可以直接用来做兜底拦截。
arXiv 2609.20974

Attention-Aware Routing：把路由与注意力耦合起来

MoE 的 router 通常只看当前 token 的隐状态、上下文信息有限。AAR 把时序与结构信息注入路由，提升专家选择的准确性。
